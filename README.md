# 내부회계통제 사무보조

금융기관 조회 업무(조회 요청 → 필요서류 확인 → 서류 발송 → 결과 회신)를 단계별 시트로 관리하는 웹 페이지입니다.

- 처음 열면 **체험판**(가상의 예시 데이터)이 보이고, 맨 위 기능 카드를 누르면 해당 기능이 있는 화면으로 이동합니다.
- **빈 양식으로 시작하기**를 누르면 실제로 기록하는 빈 양식으로 바뀝니다. (주소 끝 `?mode=app`)
- 입력한 내용은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 백업 파일 저장·불러오기·다른 사람 기록 합치기·엑셀로 복사를 지원합니다.
- 파일 하나로 동작하며 인터넷 연결 없이도 열 수 있습니다.

## 주요 기능
- 단계별 시트, 1단계 입력이 2~4단계로 자동 연동
- 담당자(알바생)별 보기
- 대상 범위(본사만·전체·일부)에 따라 회사별 인감 칸 자동 활성화
- 발송·독촉 후 경과일 표시(4일 이상이면 빨간색)
- 휴대폰에서는 카드형 화면
