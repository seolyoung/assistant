# 내부회계통제 사무보조

금융기관 조회 업무(조회 요청 → 필요서류 확인 → 서류 발송 → 결과 회신)를 단계별 시트로 관리하는 웹 페이지입니다.

- `index.html` — 처음 화면
- `demo.html` — 체험판 (가상의 예시 데이터, 새로고침하면 초기화)
- `app.html` — 빈 양식 (입력 내용은 각자의 브라우저 localStorage에 저장, JSON 백업/불러오기 지원)

## 주요 기능
- 단계별 시트 탭, 담당자(알바생)별 보기
- 대상(본사/자회사) 범위에 따라 회사별 인감 칸 자동 활성화
- 발송·독촉 후 경과일 표시(기준일 이상이면 빨간색)
- 휴대폰에서는 카드형 화면

서버 없이 HTML 파일만으로 동작하며, 별도 빌드 과정이 없습니다.

## 두 사람 기록 합치기
1. 처음 한 사람이 1단계에 금융기관 전체와 담당(1·2)을 입력하고 **백업 파일 저장** → 다른 사람에게 전달
2. 다른 사람은 **백업 불러오기**로 같은 목록에서 시작
3. 각자 자기 담당만 기록 ('보기'에서 내 담당 선택)
4. 합칠 때: 담당 2가 **백업 파일 저장** → 담당 1(또는 정리 담당자)이 **다른 사람 기록 합치기**에서 그 파일을 고르고 **담당 2 가져오기**
   - 고른 담당의 기록만 파일 내용으로 바뀌고, 내 담당 기록은 그대로 남습니다.
5. 각 시트의 **엑셀로 복사** 버튼으로 표를 복사해 엑셀에 붙여넣을 수 있습니다.
